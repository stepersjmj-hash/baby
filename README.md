# 하이츄 🎨

3~6세 아이를 위한 아이패드 학습놀이 앱. 애플펜슬로 그리고 색칠한다.
설치 없이 웹으로 돌아가고, 홈 화면에 추가하면 전체 화면 앱처럼 오프라인에서도 쓸 수 있다.

**바로 쓰기**: https://stepersjmj-hash.github.io/baby/ — 아이패드 사파리에서 열고
공유 → **홈 화면에 추가** (아래 로컬 서버 없이도 이 주소면 된다).

## 활동

- **창작** — 색칠하기 (밑그림 8종 + NAS 도안 + 내 사진 외곽선 밑그림).
  붓 7종 · 물감통 · 스티커 · 자동 저장 · 내 그림 갤러리
- **쓰기 준비** — 따라 그리기(선 긋기 22단계) · 한글 쓰기 · 이름 쓰기 ·
  숫자 쓰기(1~100) · 영어 쓰기(대문자+소문자) · 미로 찾기 · 점 잇기
- **생각 놀이** — 조각 퍼즐(내 사진 퍼즐 포함) · 다른 그림 찾기 · 세어보기 · 모양 분류
- **영상 보기(숨김)** — 설정에서 켜야 홈에 나온다. 영상은 집 NAS 에 둔다

애플펜슬 필압 반응 + 손바닥 인식, 왼손/오른손 설정, 효과음·읽어 주기(음성 팩).
활동을 고르면 무엇을 할 차례인지 말해 준다("숫자를 써 보자") — 글자를 못 읽는 나이라서다.
앞으로 만들 콘텐츠와 그 이유는 [docs/기획.md](docs/기획.md)에 정리해 두었다.

## 실행

Node만 있으면 된다. 설치할 것 없음.

```bash
node tools/serve.mjs
```

윈도우·macOS 동일하게 동작하고, 시작하면 **아이패드에서 칠 주소를 직접 찍어 준다.**

## 아이패드에 올리기

PC/Mac과 아이패드를 **같은 와이파이**에 두고,

1. 위 명령이 출력한 `http://192.168.x.x:8123` 주소를 확인한다
2. 아이패드 사파리에서 그 주소로 접속
3. 공유 버튼 → **홈 화면에 추가**

한 번 추가하면 서버를 꺼도 오프라인으로 실행된다.

## 콘텐츠 추가하기 (코드 안 고치고)

### 색칠 도안 — NAS `sketch/` 폴더

흰 바탕에 검은 선인 도안(AI 생성·다운로드 도안)을 NAS 의 `sketch/` 폴더에 올리고,
맥에서 한 줄:

```bash
node tools/make-sketch.mjs
```

새로 올렸거나 바뀐 것만 변환한다 (`--force` 로 전부 다시).
색칠하기의 그림 고르기에 카드가 생기고, 열 때 무작위 뽑기에도 섞인다.

- 숫자 파일명(`1.png`)은 "도안 1", 나머지는 파일명이 그대로 이름표
- **가로형 도안이 종이에 가장 크게 앉는다** (세로형도 되지만 좌우가 빈다)
- 일반 사진은 여기 말고 앱 안 그림 고르기의 📷 (외곽선 따기)로
- 지우려면 원본 파일을 지우고 생성기를 다시 돌린다

### 영상 — NAS `video/` 폴더

폴더 하나가 시리즈다. 새 시리즈는 폴더를 만들어 넣으면 된다:

```
video/한글용사/1.mp4 … 12.mp4     편 번호는 1부터 이어지게
video/한글용사/cover.jpg          시리즈 표지 (없어도 됨, .png 도 됨)
video/한글용사/1.jpg              그 편의 썸네일 (없으면 영상에서 자동으로 뜸)
```

폴더 **이름 목록**만 NAS 가 알려 주면 된다 — `video/list.php` 를 두면
(원본은 [tools/nas-video-list.php](tools/nas-video-list.php)) 폴더만 만들면 끝이고,
PHP 를 못 쓰면 `video/list.js` 에 한 줄: `window.HAICHU_VIDEOS = ['한글용사']`.
편수는 앱이 알아서 센다.

영상 보기는 숨김 기능이라 **홈의 설정에서 켜야** 카드가 나온다.

### 음성 바꾸기 — `assets/voice/`

앱의 모든 안내말·읽어 주기는 문구별 클립(153개)이고, 클립이 없으면 기기 TTS 로
돌아간다. 문구를 추가·수정한 뒤에는 맥에서:

```bash
node tools/make-voice.mjs
```

없는 클립을 유나 합성으로 만들어 준다. **더 자연스러운 목소리로 바꾸려면**
TTS 사이트(Airy Studio 등)에서 만든 wav/mp3 를 `assets/voice-src/` 에
**문구 이름 그대로**("기역.wav", "사과가 몇 개일까.wav") 넣고 생성기를 다시
돌리면 변환해서 갈아 끼운다. 지금은 153문구 전부 이 방식으로 교체돼 있다.

### 이름 사진 — NAS `face/` 폴더

`face/<이름>.jpg` (또는 `.png`) 를 올리면 이름 쓰기의 칩이 하트 대신
그 사람 얼굴이 된다. 없으면 조용히 하트로 남는다.

### 내 사진 — 앱 안에서

- **색칠하기**: 그림 고르기 끝의 📷 — 사진의 외곽선만 따서 밑그림이 된다
- **조각 퍼즐**: 퍼즐 화면 끝의 📷 칩 — 사진마다 8조각 퍼즐이 생긴다

둘 다 기기 안(IndexedDB)에만 저장되고, 카드를 2초 길게 누르면 지운다.
