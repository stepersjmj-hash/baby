# 아이놀이 🎨

3~6세 아이를 위한 아이패드 학습놀이 앱. 애플펜슬로 그리고 색칠한다.
설치 없이 웹으로 돌아가고, 홈 화면에 추가하면 전체 화면 앱처럼 오프라인에서도 쓸 수 있다.

## 지금 되는 것 — 색칠하기

- 밑그림 8종 (아이스크림 · 나비 · 꽃 · 물고기 · 자동차 · 고양이 · 집 · 공룡)
- 붓 7종 — 크레용 · 색연필 · 붓 · 마커 · 무지개 · 반짝이 · 꽃도장
- 물감통(선 안쪽만 칠하기) · 스티커 30종 · 지우개
- 애플펜슬 필압 반응, 손바닥 인식(손을 얹고 그려도 됨)
- 되돌리기 / 다시하기, 전체 지우기는 실수 방지용 2초 길게 누르기
- 자동 저장(앱을 껐다 켜도 이어서), 내 그림 갤러리, 사진으로 내보내기

앞으로 만들 콘텐츠와 그 이유는 [docs/기획.md](docs/기획.md)에 정리해 두었다.

## 실행

Node만 있으면 된다. 설치할 것 없음.

```bash
node tools/serve.mjs
```

윈도우·macOS 동일하게 동작하고, 시작하면 **아이패드에서 칠 주소를 직접 찍어 준다.**

## 아이패드에 올리기

PC/Mac과 아이패드를 **같은 와이파이**에 두고,

1. 위 명령이 출력한 `http://192.168.x.x:8123` 주소를 확인한다
2. 아이패드 사파리에서 그 주소로 접속
3. 공유 버튼 → **홈 화면에 추가**

한 번 추가하면 서버를 꺼도 오프라인으로 실행된다.
